============================================================
FrameTag v2 사용 설명서
문서를 바탕으로 재구성한 사진 분석·자동 이름 변경 프로그램
============================================================

[1. 이번 버전에서 추가한 기능]

선택한 폴더에 새 사진이 들어오면 자동 분석 후 이름을 변경합니다.
창을 닫아도 Windows 트레이에서 실행을 유지할 수 있습니다.
폴더, 공급자, 모델, 자동 감시 설정을 다시 켤 때 복원합니다.
API 키는 Windows 자격 증명 관리자에 공급자별로 저장합니다.
최신 문서에 있던 "현재 사진까지 선택" 수동 검토 기능도 포함합니다.

이 소스는 남아 있던 README와 설명서로 다시 작성했습니다.
분실한 원본 소스를 그대로 복원한 것은 아니므로 기존 프로그램의
모든 세부 기능·성능·분석 결과가 같다고 보장하지 않습니다.

[2. 실행]

소스 버전은 Windows에 Python 3.12 이상을 설치하고 압축을 푼 뒤
run_windows.bat을 더블클릭합니다. 첫 실행에는 인터넷이 필요합니다.
Python 설치 시 Tcl/Tk가 포함되어 있어야 합니다.

Windows에서 build_windows.bat으로 EXE를 만든 경우 dist 폴더의
FrameTag.exe를 실행합니다. EXE 실행에는 별도 Python이 필요 없습니다.
이 배포물에 Windows EXE가 없다면 Windows에서 먼저 빌드해야 합니다.

[3. 폴더와 API 키 저장]

공급자와 이미지 분석을 지원하는 모델을 선택하고 API 키를 입력합니다.
사진 폴더를 선택하면 일반 설정을 자동 저장합니다.
API 키는 입력 후 약 1초 기다리거나 입력창을 벗어나면 자동 저장합니다.
"설정 저장"으로 저장 성공을 확인할 수도 있습니다.
저장 성공을 확인하면 프로그램을 완전히 종료해도 다음 실행에 복원됩니다.
설정 JSON에는 키를 넣지 않으며 Windows 자격 증명 관리자에 저장합니다.
키 저장 실패 메시지가 나오면 저장되지 않은 것이므로 확인해야 합니다.
평문 키 파일로 대신 저장하지 않습니다.
키를 바꾸려면 새 값을 입력하고, 지우려면 입력란을 비워 저장하세요.

일반 설정 경로: %LOCALAPPDATA%\FrameTag\settings.json
API 키 발급:
  NVIDIA https://build.nvidia.com/settings/api-keys
  OpenAI https://platform.openai.com/api-keys

OpenAI API 사용 요금은 ChatGPT 구독과 별개입니다.
계정에서 사용 가능한 실제 모델 ID를 입력하거나 모델 목록을 불러오세요.
Codex 화면의 모델 이름과 API 모델 ID는 같지 않을 수 있습니다.
기본값은 NVIDIA nvidia/nemotron-nano-12b-v2-vl,
OpenAI gpt-4.1-mini입니다. 권한이나 제공 여부는 계정에 따라 달라집니다.

[4. 기존 사진은 확인하면서 처리]

1) 폴더를 선택하고 목록을 불러옵니다.
2) "남은 사진 분석"을 누릅니다.
3) 결과와 미리보기를 확인합니다.
4) 틀린 성별, 의류, 정물, 새 파일명 칸을 더블클릭해 수정합니다.
5) 마지막으로 확인한 사진을 클릭합니다.
6) "현재 사진까지 선택"을 누릅니다.
7) "선택 파일명 적용"을 누릅니다.

현재 사진까지 선택은 확인 완료 사진을 빼고 현재 행까지의
미확인 사진을 선택합니다. 이미 확인한 사진을 반복 적용하지 않습니다.
확인 완료 사진을 직접 수정하면 다시 확인이 필요한 상태가 됩니다.
Ctrl/Shift로 여러 사진을 선택할 수도 있습니다.

기준 사진을 지정한 뒤 "선택 사진 기준 통일"을 누르면 여러 사진의
성별·의류·정물을 기준 사진에 맞출 수 있습니다.
직접 수정한 의류·정물은 자동 판정 규칙으로 삭제하지 않습니다.
정물은 "우산, 상자" 또는 "우산(손), 가방(바닥)"처럼 입력합니다.
빈칸, 없음, -는 정물을 제거하는 입력입니다.

목록 검색은 파일명·분석 내용·상태를 검색합니다.
"여성 우비"처럼 여러 단어를 넣으면 모두 포함한 행만 보여 줍니다.
검색은 사진 파일을 변경하거나 API를 호출하지 않습니다.
미리보기 확대·축소와 큰 화면 보기를 사용할 수 있습니다.

[5. 새 사진 자동 이름 변경]

폴더·공급자·모델·API 키를 준비하고
"새 사진 자동 분석·이름 변경"을 체크하세요.
감시 기록이 없는 폴더를 처음 불러올 때 이미 있던 사진은
수동 검토 대상으로 남깁니다. 기존 사진은 [4]의 방법으로 처리합니다.
폴더를 불러온 이후 들어오거나 내용이 바뀐 사진은 복사가 안정된 뒤
분석하고 실제 이름을 변경합니다. 감시를 켜기 전에 추가한 사진도
감시를 켜면 자동 처리 대상이 됩니다.

자동 처리에서는 AI 결과를 사람이 확인하기 전에 이름이 바뀝니다.
처음에는 중요한 원본 대신 복사본이 있는 작은 폴더에서 확인하세요.
지원 형식은 JPG, JPEG, PNG, WEBP, GIF입니다.
GIF는 첫 프레임을 분석합니다. 하위 폴더 포함 옵션으로 범위를 정합니다.

감시 기록은 사진 폴더에 저장합니다. 같은 폴더로 다시 시작하면
종료 중 들어온 사진도 다음 실행 때 처리할 수 있습니다.
감시 기록을 지우면 기존 사진과 새 사진을 구분하던 기준이 사라집니다.

[6. 백그라운드와 완전 종료]

Windows에서 "창 닫을 때 트레이로 숨기기"가 켜져 있으면
창을 닫아도 트레이에서 실행을 유지합니다.
"백그라운드로 숨기기" 버튼을 사용할 수도 있습니다.
작업 표시줄 오른쪽의 숨겨진 아이콘 표시도 확인하세요.
FrameTag 아이콘의 메뉴에서 창 열기, 감시 일시 중지, 종료를 선택합니다.
트레이의 종료나 "완전히 종료"를 선택하거나 PC를 끄면 감시도 멈춥니다.
프로그램이 완전히 꺼진 동안 실시간으로 이름을 바꿀 수는 없습니다.
다음 실행에서 저장된 감시 기록과 비교해 새 사진을 처리합니다.

Windows 시작프로그램은 자동 등록하지 않습니다.
로그인 시 실행하려면 FrameTag.exe 바로가기를 만들고
대상에 --background 인수를 추가합니다.
Win+R에서 shell:startup을 열어 그 바로가기를 넣으세요.
폴더·키를 먼저 저장하고 감시 설정을 켜 둬야 합니다.
자동 실행을 없애려면 그 바로가기를 삭제하면 됩니다.

[7. 저장 파일과 이전 버전]

사진 폴더에 다음 관리 파일을 만듭니다.
  .frametag_v2.sqlite3       분석 결과·직접 수정·확인 상태
  .frametag_watch_v2.json    자동 감시 기준
  frametag_history_v2.json  v2 이름 변경 기록

이전 .photo_renamer_analysis_cache.sqlite3와
photo_rename_history.json은 수정하지 않습니다.
이전 결과·직접 수정·확인 상태·되돌리기 기록을 자동 이관하지 않습니다.
기존 변경은 기존 프로그램에서 되돌려야 하며 v2의 되돌리기는
v2가 만든 변경 기록에만 적용됩니다.

"마지막 변경 되돌리기"는 가장 최근의 이름 변경을 복구합니다.
다른 파일과 이름이 충돌하면 덮어쓰지 않습니다.
이름 변경 중 프로그램이나 PC를 강제 종료하지 마세요.

[8. 오류와 보안]

401/403: API 키·선택 공급자·모델 사용 권한을 확인하세요.
402/429: 결제·크레딧·사용량 또는 호출 한도를 확인하세요.
모델 오류: 계정에서 이미지 분석을 지원하는 실제 모델 ID를 확인하세요.
사진 누락: 확장자와 하위 폴더 포함 설정을 확인하세요.
키 저장 실패: Windows 자격 증명 관리자 사용 가능 여부를 확인하세요.
환경 변수 NVIDIA_API_KEY 또는 OPENAI_API_KEY로 공급할 수도 있습니다.

인증·권한·모델 없음·결제 오류는 자동 감시를 즉시 중지합니다.
호출 한도 오류도 재시도 후 계속되면 중지합니다.
그 밖의 오류도 연속 3장 발생하면 중지합니다.
원인을 해결한 뒤 "남은 사진 분석"으로 오류 사진을 다시 처리하거나,
키·모델 설정을 바꾸고 자동 감시를 다시 켜세요.

분석할 사진의 축소 사본을 선택한 외부 API로 전송합니다.
원본 픽셀은 분석 과정에서 변경하지 않습니다.
AI 분석은 틀릴 수 있고 자동 이름 변경 결과도 검토가 필요합니다.
외형상 성별 표현은 생물학적 성별이나 성 정체성을 뜻하지 않습니다.
다른 사람에게 API 키·사진·개인 설정을 포함한 파일을 보내지 마세요.

[9. 실행파일 재빌드]

Windows에서 build_windows.bat을 실행합니다.
결과는 dist\FrameTag.exe와 FrameTag-distribution.zip입니다.
ZIP에는 EXE·SHA-256 체크섬·README·이 설명서만 포함합니다.
소스 ZIP은 별도로 보관하세요.
PowerShell 실행이 차단되면 README의 실행 정책 안내를 확인하세요.
이번 소스 ZIP에는 Windows EXE가 포함되지 않습니다.
Linux에서 API 호출 없이 핵심 동작과 GUI를 검증했습니다.
Windows EXE 빌드·트레이·자격 증명 저장은 Windows에서 확인해야 합니다.
실제 API 통신은 사용자의 키·모델 권한으로 별도 확인해야 합니다.
