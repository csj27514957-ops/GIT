# FrameTag v2

사진을 NVIDIA 또는 OpenAI의 이미지 분석 API로 분석하고, 성별 표현·의류·정물을 조합한 이름으로 바꾸는 Windows 프로그램입니다.

예: `여성_검정후드_파랑청바지_손-우산_바닥-가방.jpg`

이 소스는 남아 있는 README와 사용 설명서를 바탕으로 다시 작성한 버전입니다. 유실된 원본 소스의 복구본은 아니며, 기존 EXE와 모든 세부 동작이 동일하다고 보장하지 않습니다. 최신 설명서에 있던 **현재 사진까지 선택** 기능과 수동 검토 흐름에 **새 사진 자동 이름 변경**, **트레이 실행**, **설정 저장**을 추가했습니다.

## 처음 실행하기

1. Windows 10/11에 [Python 3.12 이상](https://www.python.org/downloads/windows/)을 설치합니다. 설치 구성의 Tcl/Tk 항목을 포함해야 합니다.
2. 소스 ZIP을 완전히 풀고 `run_windows.bat`을 더블클릭합니다. 첫 실행에 가상 환경을 만들고 필요한 패키지를 설치하므로 인터넷이 필요합니다.
3. 공급자, 이미지 분석을 지원하는 모델, API 키를 지정합니다. NVIDIA 기본 모델은 `nvidia/nemotron-nano-12b-v2-vl`, OpenAI 기본 모델은 `gpt-4.1-mini`입니다. 계정에서 실제 사용 가능한 모델 ID를 입력하거나 모델 목록을 불러올 수 있습니다.
4. 사진 폴더를 선택하고 설정을 저장합니다. API 키 저장에 실패했다는 메시지가 나오면 키가 저장되지 않은 상태이므로 원인을 확인합니다.
5. 기존 사진은 목록을 불러와 **남은 사진 분석 → 결과 확인/수정 → 현재 사진까지 선택 → 선택 파일명 적용** 순서로 처리합니다.
6. 새 사진을 곧바로 이름 변경하려면 **새 사진 자동 분석·이름 변경**을 체크합니다.

API 키는 [NVIDIA](https://build.nvidia.com/settings/api-keys) 또는 [OpenAI](https://platform.openai.com/api-keys)에서 발급합니다. ChatGPT 구독과 OpenAI API 결제는 별개입니다. 모델 사용 권한·요금·한도는 각 계정에 따릅니다. 기존 문서의 `GPT-5.6 Luna/Terra/Sol` 같은 Codex 모델 이름을 실제 공개 API 모델 ID로 사용하지 않습니다.

## 자동 감시와 백그라운드 실행

- 감시 기록이 없는 폴더를 처음 불러올 때 이미 있던 사진은 수동 검토 대상으로 남깁니다. 기존 사진은 자동 변경하지 않으며 수동으로 분석하고 적용할 수 있습니다.
- 폴더를 불러온 이후 새로 들어오거나 내용이 바뀐 지원 사진은 자동 감시를 켜면 파일 복사가 안정된 뒤 분석하고 실제 이름을 변경합니다. 감시를 켜기 전에 추가한 사진도 대상입니다. 프로그램이 만든 이름 변경을 새 사진으로 다시 분석하지 않도록 감시 기록을 유지합니다.
- 감시를 켠 기록과 폴더를 저장하면 다시 실행할 때 설정을 복원합니다. 저장된 감시 기록을 바탕으로 종료 중 들어온 사진도 다음 실행 때 처리합니다.
- Windows에서 **창 닫을 때 트레이로 숨기기**가 켜져 있으면 창을 닫아도 실행을 유지합니다. **백그라운드로 숨기기** 버튼이나 트레이 메뉴에서 창 열기·감시 일시 중지·종료를 사용할 수 있습니다.
- **트레이에서 완전 종료하거나 PC를 끄면 감시도 멈춥니다.** 이 프로그램은 Windows 서비스가 아니며 시작 프로그램을 자동 등록하지 않습니다.
- 자동 처리는 AI 결과를 사람이 확인하지 않고 파일명에 적용합니다. 처음에는 복사해 둔 작은 테스트 폴더에서 결과를 확인하세요. 파일명 변경 기록으로 최근 변경을 되돌릴 수 있습니다.
- API 인증·권한·모델 없음·결제 오류는 감시를 바로 중단합니다. 호출 한도 오류도 재시도 후 계속되면 멈추며, 그 밖의 오류는 연속 3장 발생하면 중단합니다. 키·모델·사용량 등의 원인을 해결하고 **남은 사진 분석**으로 오류 사진을 다시 분석하거나, 설정을 바꾼 뒤 자동 감시를 다시 켜세요.

하위 폴더 포함 옵션을 켜면 하위 폴더도 대상이 됩니다. 지원 형식은 JPG, JPEG, PNG, WEBP, GIF이며 GIF는 첫 프레임을 분석합니다.

## 폴더와 API 키 저장

폴더·공급자·모델·감시 설정 등은 `%LOCALAPPDATA%\FrameTag\settings.json`에 자동 저장합니다. API 키를 입력하고 약 1초 기다리거나 입력창에서 벗어나면 **Windows 자격 증명 관리자**에 공급자별로 저장합니다. **설정 저장** 버튼으로 저장 결과를 확인할 수 있습니다. 키는 JSON에 넣지 않습니다. 폴더를 옮기거나 새 EXE로 교체해도 같은 Windows 사용자 계정이면 설정을 다시 사용할 수 있습니다.

키 저장이 불가능한 환경에서는 평문 파일로 우회 저장하지 않습니다. `NVIDIA_API_KEY`, `OPENAI_API_KEY` 환경 변수로 키를 공급할 수도 있습니다. 저장된 키를 바꾸려면 새 키를 입력하고, 삭제하려면 키 입력란을 비워 저장하세요. 다른 사람에게 공유하는 ZIP에는 본인의 API 키·사진·설정 파일을 넣지 마세요.

## 수동 검토 기능

- `성별`, `의류`, `정물`, `새 파일명` 셀을 더블클릭해 수정합니다. 직접 입력한 의류·정물은 자동 정형화 규칙으로 지우지 않습니다.
- `Ctrl` 또는 `Shift`로 사진을 여러 장 선택합니다. 기준 사진을 지정하고 **선택 사진 기준 통일**을 누르면 선택한 사진의 결과를 맞출 수 있습니다.
- **현재 사진까지 선택**은 현재 행까지의 미확인 사진을 선택하며 확인 완료 사진은 제외합니다.
- 목록 검색은 파일명·결과·상태를 검색합니다. 띄어쓴 검색어는 모두 포함되어야 표시됩니다.
- 미리보기의 확대/축소와 큰 화면 보기를 사용할 수 있습니다.
- 분석 결과·수동 수정·확인 완료 상태는 사진 폴더의 캐시에 저장합니다. 같은 폴더를 다시 불러와 작업을 이어갈 수 있습니다.
- **마지막 변경 되돌리기**는 해당 사진 폴더의 가장 최근 변경 기록을 되돌립니다. 변경 전후 이름에 다른 파일이 있으면 덮어쓰지 않고 충돌을 알립니다.

AI는 사진에 보이는 주된 인물의 외형상 표현만 분류하며 생물학적 성별이나 성 정체성을 판정하지 않습니다. 자동 분석은 틀릴 수 있습니다. 분석용 축소 사본은 선택한 API로 전송되며 원본 픽셀은 수정하지 않습니다.

## 이전 버전 파일과의 관계

v2는 `.frametag_v2.sqlite3`, `.frametag_watch_v2.json`, `frametag_history_v2.json`을 사진 폴더에 사용합니다. 이전 버전의 `.photo_renamer_analysis_cache.sqlite3`와 `photo_rename_history.json`은 읽거나 바꾸지 않습니다. 기존 캐시의 수동 수정·확인 상태·되돌리기 기록이 v2로 자동 이관되지는 않습니다. 이전 변경은 기존 프로그램에서 되돌리고, v2의 되돌리기는 v2에서 만든 기록에만 적용하세요.

캐시와 감시 기록을 삭제하면 분석/감시 이력이 없어집니다. 특히 감시 기록이 없는 폴더의 기존 사진은 최초 기준으로 취급되므로, 자동 처리할 사진을 별도 수동 분석해야 할 수 있습니다.

## Windows EXE 만들기

Windows에서 `build_windows.bat`을 더블클릭하거나 PowerShell에서 다음을 실행합니다.

```powershell
./build_exe.ps1
```

결과는 `dist\FrameTag.exe`, `dist\FrameTag_SHA256.txt`, `FrameTag-distribution.zip`입니다. ZIP에는 실행파일·체크섬·두 설명서만 들어갑니다. 소스코드는 별도로 보관하세요. 빌드에는 인터넷과 Python 3.12 이상이 필요합니다. 만든 EXE 실행에는 별도 Python이 필요 없습니다. 이 프로젝트에서 Windows 실행파일을 Linux에서 빌드하지 않습니다.

PowerShell이 스크립트 실행을 차단하면 파일 내용을 확인한 뒤 현재 창에만 다음 설정을 적용할 수 있습니다. 컴퓨터 전체의 정책은 바꾸지 않습니다.

```powershell
Unblock-File ./build_exe.ps1
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
./build_exe.ps1
```

이 빌드는 상용 코드 서명이나 공식 인증을 포함하지 않습니다. 출처가 확인된 소스로 직접 빌드하고 체크섬을 함께 보관하세요.

## 로그인 시 자동 실행하기

EXE를 만든 후 `FrameTag.exe`의 바로가기를 생성해 대상 끝에 ` --background`를 붙입니다. `Win + R` → `shell:startup`으로 연 시작프로그램 폴더에 바로가기를 넣으면 로그인할 때 트레이로 시작합니다. 폴더와 키를 먼저 저장하고 감시를 켜 둬야 자동 처리됩니다. 등록 해제는 그 바로가기만 삭제하면 됩니다.

소스로 실행할 때는 `.venv\Scripts\pythonw.exe`를 대상으로 하고 인수에 `"전체경로\app.py" --background`를 지정할 수 있습니다. `run_windows.bat`은 의존성 설치용 콘솔이 열리므로 로그인 시 실행에는 EXE나 `pythonw.exe` 바로가기를 사용하세요.

## 개발 및 검증

```powershell
py -3 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m unittest discover -s tests -v
./.venv/Scripts/python.exe app.py
```

이번 소스 ZIP에는 Windows EXE가 포함되지 않습니다. Linux에서 실제 API 키와 사진 업로드 없이 핵심 동작 및 GUI를 검증했으며, Windows 자격 증명 관리자·트레이·EXE 빌드는 실제 Windows에서 추가 확인해야 합니다. 실제 API 응답은 해당 계정의 키와 모델 권한으로 확인해야 합니다.
